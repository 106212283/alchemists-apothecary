
# Alchemist's Apothecary

## Project Overview

Alchemist's Apothecary is an interactive potion-brewing game developed using Ruby and Gosu for COS10009 Introduction to Programming.

The player manages an ingredient shop, creates magical potions and serves customers to earn gold and reputation.

## Game Features

- Interactive ingredient shop
- Inventory and gold management
- Random customer selection
- Animated cauldron
- Real-time potion colour blending
- Potion match scoring
- Customer satisfaction system
- Reputation-based ingredient unlocking
- Three progressive difficulty levels
- Final performance summary
- Input validation and error handling

## Difficulty Levels

| Level | Customers | Minimum Ingredients |
|-------|-----------|---------------------|
| Apprentice | 1-3 | 2 |
| Skilled | 4-6 | 3 |
| Master | 7-10 | 4 |

## Requirements

- Ruby
- Gosu library

## How to Run

Install Gosu:

    gem install gosu

Run the game:

    ruby alchemist.rb

## Controls

- Left mouse button: Interact
- F11: Toggle fullscreen
- R: Restart game
- ESC: Exit game

## Project Files

- alchemist.rb - Main game program
- ingredients.txt - Ingredient data
- customers.txt - Customer data
- screenshots/ - Gameplay and testing evidence
